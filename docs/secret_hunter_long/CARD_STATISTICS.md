# 卡位曝光分层

场次按对局计，因此双卡实体次数可超过场次。伤害仅为该实体直接伤害，恐狼光环、奥秘及误导的间接贡献未归因。
回合以己方自然最大法力标记，硬币可使牌提前使用。完整首次可打与延迟分布保存在每批analysis JSON。
