# Failure and mechanism review

`diagnostics.json` preserves ten early P2/P0 divergences from P0 development losses: full public state, source game/sequence, chosen and alternative legal actions, and official-engine continuation through that turn under the same P0 continuation policy. These are neither ten independent match wins nor a complete explanation of every loss. All twenty valid branches ended nonterminal. No individual changed-winner claim is made.

Examples: in game `472931320812486a`, turn 13, Kill Command could remove a 6/5 Ogre instead of the 3/1 taunt. The alternatives produced different enemy boards and four points of face-damage opportunity cost, not a proven win. In `6e6968e132454769`, turn 3, a Dire Wolf-buffed Leper Gnome could trade into Faerie Dragon while preserving the same hero damage through its deathrattle. In `b25a9edacd9d4e4f`, turn 5, using the power before development gained two face damage but lost Keeper growth; this exposes why search can regress when strong unsupported Secret development is not fully simulated. Several other earliest divergences simply changed action order and reached the same end board.

| Category | Evidence and conclusion |
|---|---|
| Rules / simulation | 732 supported one-step comparisons from 36 development game families matched the official engine. They did not cover every random branch. A later identity audit found and fixed swapped Misha/Huffer constants in an inactive helper; aggregate 1/3 probability tests had failed to detect the label error. F2 has ID-specific engine regression checks and separate fresh confirmation. |
| Missed lethal | Five base deterministic tactical families plus two compound armor/taunt/shield/weapon lines are engine checked. Bounded search may still miss a line; absence of a proof is not a proof of no lethal. Unsupported/random positions are explicitly excluded from guaranteed claims. |
| Avoidable death | A three-mana Kill Command plus Highmane trade removes known Ogre lethal; spending the two-mana hero power first loses that line. The regression verifies the legal defense in the actual engine. Hidden burst is not asserted absent. |
| Trade / placement | Seven of the ten recorded earliest divergences are attacks. Dire Wolf positions are enumerated, but depth/width pruning and excluded triggers can still lose combinations. Local board improvements do not imply full-game wins. |
| Secret timing | Engine fixtures cover Explosive/Freezing order, Bow durability, attack cancellation, shield survival, minion-target Freezing and exchange-first avoidance. Extra conditional Secret penalties did not add stable aggregate benefit and remain disabled. |
| Resource use | Three earliest divergences concern card/power choices. Hand preservation and renewable power are explicit search features. The larger survival/resource reranking module did not improve validation and is disabled. |
| Combo order | Affordable Juggler/Hyena-Hounds rules are retained; multi-Juggler random summons are intentionally rejected by deterministic projection. Actual random outcomes trigger replanning. Expanded combo bonuses did not improve validation. |
| Mulligan | Fixed early-curve/Keeper mulligan retained. This round did not demonstrate an independently improved mulligan policy. Bad draws are not automatically labelled mulligan errors. |
| Compute budget | No observed normal-game illegal action, timeout, program exception or >2-second internal decision. Forced hang/crash/tiny-budget tests retain legal program actions, kill the worker and preserve a published best action. A test harness initially injected the wrong function signature after an API extension; that run is retained and the hang test was corrected to assert an actual timeout. |
| Draw / random variance | Paired seeds control the schedule but not identical post-divergence random trajectories. Outcome intervals include that variance; unclassified losses are not all attributed to randomness. No hidden seed, hand or RNG is used by the strategy. |

The first diagnostic harness version read own hero attack count from the reconstructed engine. It was excluded (`diagnostics-rejected-source.json`) and rerun using only recorded public events and replayed public actions; the twenty excluded branches remain charged to the budget. No training match used that harness input. An early differential-run setup failure (`Engine.view` lacks the runner's `player` field) occurred before any branch and was corrected to use recorded public observations.

Weak areas remain wide sticky boards, taunts plus sustained removal, and positions outside the partial simulator's coverage. On the larger F1 block, tempo Paladin regressed from 49/60 to 46/60 and control Mage improved only from 45/60 to 46/60; F2's small block still lost 6/20 against adversarial Zoo and 5/20 against search Paladin. The next useful work is targeted public-effect coverage and opponent board-response evaluation, with counterfactual cases and fresh seeds; another broad heuristic layer is not supported by this round.
