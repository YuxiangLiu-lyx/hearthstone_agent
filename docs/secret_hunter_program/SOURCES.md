# Sources and portability decisions

All references were read as research, not executed or reproduced. Exact commits, fetched paths, URLs and content SHA-256 values are in `reference-fetch.json`; downloaded external source stays under `/tmp/secret-hunter-program-references-20261111`, outside the submission. New Python implementations reuse this repository's own policy and implement the ideas independently. No external simulator, automation client or model dependency is vendored.

Course sources read: [current assignment](https://bu-agenticai-class-fall26.vercel.app/materials/assignments/hw2.md), local `hs-arena-0.2.2/README.md`, `docs/handout.md`, `docs/protocol.md`, `examples/greedy_skill` and the complete `examples/greedy_mcp_client/client.py`. The current FAQ explicitly permits Python decision-making with model relay. The MCP transport example is reused from the supplied course interface; policy is the same supervised Python implementation. The validator requires `model: luna` (medium effort supplied by the host), not the underlying model ID. Course decision timeout remains 180 seconds; internal target is 2 seconds.

Historical strategy sources already read in the prior development round and retained as development references: [DimfrostHS, 2016 Secret Hunter guide](https://www.reddit.com/r/CompetitiveHS/comments/55dois/top_200_legend_with_obsolete_secret_hunter_64_wr/) (Keeper/Secrets, Juggler/Hounds); [Kat, Hunter Secrets](https://www.icy-veins.com/hearthstone/hunter-secrets) (baiting and order); [Kat, Midrange Hunter](https://www.icy-veins.com/hearthstone/midrange-hunter-deck) (curve, board control and late threats); [Flores, Who's the Beatdown?](https://articles.starcitygames.com/articles/whos-the-beatdown/) (role depends on clocks). Their decklists and modern card versions are not adopted. Actual course text and engine fixtures override guides, especially Tracking's discard, own-only Secretkeeper trigger and Secret ordering.
