# Fixed Secret Hunter program

The exact requested 30-card deck has 19 unique IDs, six Secrets, Acidic Swamp Ooze and King Krush; it has no Snipe. The course validates class, copies and legendary restrictions. Deck SHA-256 is `54c475d2f72ff3a36ec5d47d0e34bf33625eb1b20c75f213e171c73719cf61f4`.

`program_policy.decide(public_state, config)` is the sole decision implementation. The batch player passes only the official public observation and current-game public event history. `scripts/decide.py` supervises the same function in a killable worker. The official skill model runs that command and copies its `seq/action`; it has no strategic selection step. `client.py` uses the supplied official stdio MCP interface without a model.

A legal fallback is ready before expensive imports or search. The program ranks legal templates using the retained Hunter curve, secret, weapon and combo rules, then searches for a covered deterministic lethal. Failing a proof, a finite beam compares possible end-of-turn boards with health, attack, shields, taunts, hand resources, weapon charges and an explicit penalty for exposed board lethal. It can end the turn at any searched node; unspent mana is not permission to invent an unmodelled card effect. A strong unsupported top-ranked action retains the ranking fallback so the search does not silently exclude random or unsupported development.

The retained parameters are `turn_face=1.116`, `turn_board=1.094`, `turn_hand=0.973`, `turn_risk=3.273`, width 10, depth 9, 350 turn-search nodes and an 80 ms local search allocation. The independent lethal check has 1,600 nodes and 150 ms. Both operate inside a monotonic 1.5-second soft deadline; the parent kills a noncooperative worker near 1.8 seconds to leave output margin for the 2-second internal target. Nodes, width and depth supplement deadline checks. This is measured engineering behavior, not a hard real-time guarantee under arbitrary OS or I/O stalls.

States are deduplicated during search. Exact repeated observations use a configuration/state fingerprint cache. A separate predicted-continuation cache was implemented and tested against changed health, sequence and game identity; its validation result did not improve wins, so F2 disables it. The retained policy executes one action and replans from the actual observation, including after knives, draws and Secret outcomes. No cached sequence can carry between games.

Guaranteed lethal is restricted to supported deterministic effects. Unknown enemy Secrets, unsupported persistent effects, unobserved draws and random summon triggers stop those branches. Public armor, shields, poison, taunts, mana, adjacency, beast deaths, Highmane tokens and a limited set of charge/weapon interactions are projected. Juggler summons, Misdirection and Tracking outcomes are handled by the real engine and subsequent observations. The optional three-way Companion probability helper is for diagnostics; F2 corrects the inherited Misha/Huffer ID swap and explicitly validates branch identities. It is not called by the active strategy. Its lower bound on discovered chance lethals is not a general win probability.

Secrets are delayed conditional resources. An active Explosive Trap never removes an enemy from the board evaluator. Shields, avoidance, small attackers and pre-face trades can defeat its expected value. Existing guide rules account for Keeper/Bow, board slots, weak Freezing bait and Explosive-before-Freezing ordering. Actual affordability gates Juggler/Hyena before Hounds; beast availability affects Kill Command, and Dire Wolf placement is expanded. Last Bow charge retention is conditional, while lethal overrides conservation. Ooze can develop or destroy a visible weapon. Tracking chooses among the real offered cards, and mulligan follows early curve/Keeper support rules.

There is no inferred exact opposing deck or hand. Public class/history features remain uncertain; hidden archetype sampling is not used. Own hero attack availability is reconstructed only from complete public turn events. Opponent names, seed, RNG state and engine objects never enter the policy. The simulator is a deliberately partial public-effect projector, not a replacement for the official engine.
